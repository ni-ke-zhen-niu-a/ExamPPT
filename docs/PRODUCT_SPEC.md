# ExamPPT V0.1 产品边界

## 正式名称
- 英文：ExamPPT
- 中文：PDF试卷无损转PPT 工具

## 用户
以国内中小学教师为第一用户群。优先支持 Windows 10 / 11 x64。

## 输入
PDF 试卷。数字 PDF 优先自动识别；扫描/混合 PDF 允许自动识别失败后手动调整题目边界。

## 输出
1. 普通讲评版 PPTX
2. 答案逐步揭示版 PPTX
3. QA 报告
4. 放映画面预览

PPTX 必须同时可在 Microsoft PowerPoint 与 WPS 演示中打开和讲课。

## 可靠性硬规则
- 原题不改；
- 顺序不变；
- 整题不跨页；
- 统一视觉尺度；
- 放不下先压缩纯空白，再单独占页；仍放不下则标记人工处理；
- 生成结束不是完成，结构 QA 与实际放映画面检查均应通过。

## PDF ↔ PPT 对照
GUI 采用左右双栏：
- 左：原始 PDF
- 右：生成后的 PPT 放映画面
- 中/侧栏：题号导航
点击题号时两侧自动跳到同一道题。

## 答案逐步揭示
V0.1 只接收原卷答案、独立答案文件或人工录入答案，不自动解题。
使用“状态幻灯片”实现逐步揭示，优先保证 PowerPoint/WPS 兼容，而不是依赖复杂动画 XML。

## 发布
GitHub 为 Source of Truth；Gitee 为国内镜像和下载源。
正式发布使用版本标签，例如 v0.1.0；同时维护 Gitee 的 latest 分发入口，使国内用户获得固定的一键下载 URL。
